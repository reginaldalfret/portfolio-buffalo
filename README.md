### 4. Prerequisites & Local Development

#### Prerequisites
- Go 1.22+ (Go 1.24 recommended)

#### Installation
```bash
git clone https://github.com/reginaldalfret/portfolio-buffalo.git
cd Portfolio-Buffalo
go mod download
```

#### Running Development Server
```bash
go run main.go
```

#### Production Build
```bash
go build -o bin/app
```

#### Running Test Suite
```bash
go test ./...
```
